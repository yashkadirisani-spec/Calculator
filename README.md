# Calculator

A simple Calculator that is able to switch color styles between Apple and Android. 

#features
- Contains a button that switching between Portrait and landscape. + another button to select Apple or Android style calculator.
- Interactive UI

#setup
- Download the html, CSS(2 files), and the JavaScript file in the "Calculator" Folder.
- when everything is downloaded, Run the the HTML file in any code editor. 

# For Calculator NODE

How to run,

Download all files ONLY in 'CalcwithNODE'
run the HTML file first.
open server.js, and in your terminal type "node server.js" to start the server
Calculations are able to be done now.
